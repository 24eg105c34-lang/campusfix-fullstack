# CampusFix Frontend
Responsive HTML/CSS/JavaScript frontend for CampusFix.

## Run locally
1. Start the backend on `http://localhost:8080`.
2. Open `index.html` in a browser, or serve this folder with any static web server.
3. For a hosted API, edit `API_BASE` at the top of `app.js`.

This is a demo frontend. Authentication, image upload, and admin-only permissions are future enhancements.
